# Hey, I'm Ramiro 👋

### I build resilient platforms and agentic systems that hold up in production.

<samp>agentic workflows · harness engineering · platform engineering · cloud reliability</samp>

</div>

I design and operate cloud-native platforms with a focus on **resilience, automation, and operational simplicity**. Increasingly, that means building the infrastructure and engineering harnesses that turn capable AI models into dependable, observable systems.

My work sits where Kubernetes, multi-cloud infrastructure, agentic AI, security, observability, and real-world failure modes meet.

> Infrastructure should scale with the business, not with operational pain.

### What I'm building

- Building active-active, multi-region Kubernetes platforms
- Modernizing legacy infrastructure without disrupting production
- Designing production-grade agentic workflows with tools, memory, and human checkpoints
- Engineering agent harnesses: context assembly, execution boundaries, retries, and durable state
- Adding evaluation, tracing, guardrails, and failure analysis to AI delivery loops
- Improving observability, delivery safety, performance, and cloud cost across the stack

### Agentic systems & harness engineering

I care about the **whole system around the model**. A good demo is easy; a useful agent needs clear contracts, the right context, safe tools, measurable outcomes, and predictable behavior when dependencies fail.

| Area | What I focus on |
|---|---|
| **Agentic workflows** | Tool-using agents · multi-step planning · human-in-the-loop flows · multi-agent coordination |
| **Harness engineering** | Context engineering · MCP integrations · sandboxed execution · state and checkpointing |
| **Quality & safety** | Evals · tracing · guardrails · replayable runs · structured failure analysis |
| **AI platform** | Model gateways · workload orchestration · secure tool access · scalable inference foundations |
| **Developer experience** | Automation that reduces toil while keeping engineers in control |
